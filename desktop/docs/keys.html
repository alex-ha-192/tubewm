tubewm

keys

Every shortcut the tubewm Sway desktop sets up. Super is the Windows or logo key. You can change any of them in ~/.config/sway/config.

shellwindowssnappivotsstartgesturesmediabar
stuck?

Super + Return opens a terminal, Super + Shift + E shows sign out and power, and Super + Shift + C reloads the config. From a text console (Ctrl + Alt + F3), pkill -x sway ends the session.
