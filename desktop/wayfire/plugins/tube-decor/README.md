# tube-decor

Wayfire's own `decoration` plugin (MIT, from Wayfire 0.10) with Metro title
bars: a flat bar, the title on the left at 15px, and square buttons the full
height of the bar. The close X fills red on hover. Options live in
`[tube-decor]` and match `[decoration]`'s.

Changed from upstream: `deco-theme.cpp` (title and button drawing),
`deco-layout.cpp` and `deco-button.*` (button size), the option section name,
and `tube-decor.xml`. See `LICENSE` for the upstream notice.
